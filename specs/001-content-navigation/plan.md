# 实现计划：三级内容导航、文章与首页视频

**日期**：2026-10-14
**规格**：[spec.md](spec.md)
**阶段**：第 2 步设计已完成并获批准；第 3 步本地 MVP 已实现，待交付试用反馈进入第 4 步。

## 技术路线

沿用现有 Next.js 16 + Payload 3 + SQLite 单体应用与现有管理员账户，不另建后台。Payload 新增菜单、文章和视频上传数据；现有 Company 首页配置增加一个可选视频关系。前台新增三级菜单、文章列表与详情，并将既有首页轮播继续接到后台数据。

PoC 已证明当前 Payload/SQLite 栈能接受并保存 MP4。本地 MVP 已验证真实路由返回 Range/206、30 MB 上限与首屏零视频元素/请求；公网带宽效果仍需上线前实测。

## 实施顺序

1. **数据和规则**：新增 `Menus`、`Articles`、`Videos` Collection 与数据库迁移。菜单保存时验证深度、循环、移动后子树深度、唯一 slug；删除时拒绝仍含子菜单/文章的菜单。文章必须归属一个菜单。管理员写入权限沿用现有规则。
2. **公开内容读取**：实现只返回已发布且祖先均已发布的菜单/文章的查询；对公开详情路由做同样过滤。富文本按 Payload 支持的安全节点渲染，图片 URL 与替代文字来自受控上传库。
3. **前台 UI**：沿用现有视觉 token、首页、产品与询盘入口；增加 B 横向三级菜单，手机端改为分层可点面板；每层分别有展开和「查看本级文章」入口。增加文章列表、详情、空状态、面包屑与无图版式。
4. **首页视频**：独立 MP4 上传 Collection，限制 MIME 和 30 MB；检查文件实际内容。Company 只关联一条可选已发布视频。初始 HTML 只输出封面与播放按钮，点击后才设置 `src` 和创建播放器；服务器验证 206/Range。同步调整 Payload 上传限制与 Nginx 限制，保留图片现有限额。
5. **验收和交付**：覆盖后台增改/发布/下线、三级限制与循环、所有层级文章、有图/无图、轮播回归、视频首屏零请求和点击播放；桌面/手机点测；构建通过后更新 README/HANDOFF 与本地交付包。

## 改动位置

- `src/collections/`：新菜单、文章、视频集合，以及必要的访问规则。
- `src/globals/Company.ts`：可选首页视频关系。
- `src/endpoints/public-content.ts`、`src/app/(frontend)/`、`src/components/`：公开查询、路由及界面。
- `src/payload.config.ts`、`src/migrations/`、`deploy/nginx.conf`：注册、迁移和上传配置。
- `scripts/verify-backend.ts` 与浏览器验收：可回归的行为检查。

不引入新服务、独立前后端、转码队列或 CDN。部署前按真实授权素材和 3 Mbps 带宽再评估视频体积；若实际素材超过 30 MB，本轮先压缩素材后上传，不隐式放宽上限。

## 放行条件

- 当前设计原型已点击检查：三个层级的入口、带图/无图详情、后台三块编辑界面、手机布局；初始无 video 元素，点击后才设置 MP4 `src`。这只验证设计交互，**不等同于生产功能通过**。
- 用户批准本规格与计划后进入第 3 步。正式实现完成后，须有真实测试输出才能宣称 MVP 可交付。
- 域名/备案/HTTPS/阿里云登录和真实资料属于正式上线条件，不能用本地 MVP 验收替代。
