# 春昌官网普通人操作手册

这份手册写给完全没有计算机基础的人。你不需要懂代码，按步骤操作即可。

公司名：

```text

春昌（山东）健康科技有限公司
```

官网地址：

```text
http://chunchang.tech/sites/chunchang
```

后台登录地址：

```text
http://chunchang.tech/login
```

说明：当前服务器先使用 HTTP。等开发人员配置 HTTPS 证书后，地址会升级为 `https://chunchang.tech`。

默认后台账号：

```text
账号：admin@xiao9.com
密码：admin123
```

第一次正式上线后，请尽快让开发人员帮你修改默认密码。

## 1. 每天怎么打开网站

1. 打开浏览器。
2. 在地址栏输入：

```text
http://chunchang.tech/sites/chunchang
```

3. 按回车。
4. 看到公司官网页面，就说明前台网站正常。

如果打不开，先截图发给开发人员。截图里要包含浏览器地址栏和错误页面。

## 2. 怎么进入后台

1. 打开浏览器。
2. 在地址栏输入：

```text
http://chunchang.tech/login
```

3. 输入账号：

```text
admin@xiao9.com
```

4. 输入密码：

```text
admin123
```

5. 点击“登录”。
6. 能看到后台页面，就说明登录成功。

如果登录失败，看页面右上角或弹窗提示。报错已经尽量改成中文，直接把中文报错发给开发人员即可。

## 3. 怎么改公司首页内容

1. 登录后台。
2. 进入“站点管理”。
3. 找到“春昌”站点。
4. 点击“内容管理”。
5. 在页面里找到“站点配置”或类似区域。
6. 可以修改：
   - 公司名称
   - 首页标题
   - 首页副标题
   - 关于我们
   - 合作机会
   - 电话
   - 微信
   - 地址
7. 修改后点击“保存”。
8. 打开官网：

```text
http://chunchang.tech/sites/chunchang
```

9. 刷新页面，看修改是否生效。

注意：没有确定的企业资料不要乱写，比如成立年份、证书、产能、合作客户等。没有真实资料时先留空或写“待补充”。

## 4. 怎么维护菜单

菜单就是官网顶部的栏目，比如：

```text
首页
产品服务
关于我们
最近动态
合作机会
联系我们
```

操作步骤：

1. 登录后台。
2. 进入“站点管理”。
3. 点击春昌站点的“内容管理”。
4. 找到“菜单栏目”区域。
5. 点击“新增菜单”。
6. 填写菜单名称，比如：

```text
产品知识
```

7. 填写访问标识，只能用小写英文、数字和横线，比如：

```text
product-knowledge
```

8. 选择上级菜单。
9. 点击保存。

菜单最多可以有三级。菜单可以随意挂在其他菜单下面。

## 5. 怎么写文章

文章只能挂在最后一级菜单下面。

举例：

```text
产品服务
  └── 黄油产品
      └── 文章可以挂在这里
```

如果一个菜单下面还有子菜单，就不能直接挂文章。

操作步骤：

1. 登录后台。
2. 进入春昌站点的“内容管理”。
3. 找到“文章”或“栏目文章”区域。
4. 选择一个最后一级菜单。
5. 填写文章标题。
6. 填写访问标识，比如：

```text
butter-product-intro
```

7. 填写摘要。
8. 在富文本编辑框里写正文。
9. 可以插入：
   - 加粗文字
   - 标题
   - 列表
   - 链接
   - 图片
   - 视频地址
10. 点击保存。
11. 确认内容无误后，再点击发布。

如果文章只是草稿，前台用户看不到。发布后前台才会展示。

## 6. 怎么上传图片

1. 登录后台。
2. 进入内容管理。
3. 找到图片上传按钮。
4. 点击上传。
5. 选择电脑里的图片。
6. 上传成功后，系统会返回一个图片地址，一般长这样：

```text
/uploads/xxxx.jpg
```

7. 把这个地址填到图片 URL 输入框，或插入到富文本编辑器里。
8. 保存文章或页面。
9. 到官网刷新查看图片是否显示。

建议图片不要太大。普通产品图建议先压缩到 1MB 以内。

## 7. 怎么查看客户留言

客户在官网提交咨询后，后台会记录线索。

操作步骤：

1. 登录后台。
2. 进入春昌站点的“内容管理”。
3. 找到“留言线索”或“咨询线索”区域。
4. 查看客户填写的：
   - 姓名
   - 电话
   - 公司
   - 合作类型
   - 咨询内容
5. 联系客户后，可以把状态改成“已跟进”或类似状态。

客户电话和咨询内容不要随便截图发到公开群里。

## 8. 怎么判断网站正常

每天可以检查这几个地址：

```text
http://chunchang.tech/sites/chunchang
http://chunchang.tech/login
http://chunchang.tech/actuator/health
```

正常情况：

- 官网能打开。
- 后台登录页能打开。
- 健康检查页面显示 `UP`。

如果健康检查打不开或不是 `UP`，发给开发人员处理。

## 9. 遇到报错怎么办

现在系统报错会尽量用中文弹窗提示。

你需要做三件事：

1. 不要连续乱点。
2. 截图。
3. 把截图和你刚才做的操作发给开发人员。

描述方式可以这样写：

```text
我在后台新增文章时，点击保存后报错。
报错内容是：没有权限执行此操作，请确认账号权限。
我使用的页面是：http://chunchang.tech/dashboard
```

常见中文报错含义：

| 报错 | 意思 |
| --- | --- |
| 没有权限执行此操作，请确认账号权限。 | 当前账号权限不够，或登录状态有问题 |
| 登录已过期，请重新登录。 | 重新打开登录页登录 |
| 无法连接服务器，请确认服务已启动或网络正常。 | 后台服务可能没启动，找开发人员 |
| 请求超时，请稍后再试。 | 网络慢或服务器忙，等一会再试 |
| 请求参数不正确，请检查填写内容。 | 表单里有内容格式不对 |

## 10. 修改内容后前台没变化怎么办

按顺序检查：

1. 后台是否点击了保存。
2. 文章是否点击了发布。
3. 浏览器是否刷新了页面。
4. 菜单下面是否真的挂了文章。
5. 文章是否挂在最后一级菜单下面。

如果都检查过还是不变，截图发给开发人员。

## 11. 不要做的事

- 不要删除服务器文件。
- 不要修改 `.env.prod`。
- 不要在后台乱填不存在的资质、产能、客户案例。
- 不要把后台账号密码发到公开群。
- 不要把客户留言截图发到公开群。
- 不确定的内容先保存草稿，不要直接发布。

## 12. 一句话流程

日常维护就按这个顺序：

```text
登录后台
→ 修改菜单/文章/产品/联系方式
→ 保存
→ 发布
→ 打开官网刷新检查
→ 有客户留言就及时跟进
```

能完成以上流程，就可以维护当前官网。
