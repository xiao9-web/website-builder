# 春昌官网第二版设计规则

日期：2026-10-13。第 2 步设计已于 2026-10-13 获得用户选择 A，点击验收通过；2026-10-14 本地第 3 步试用版已完成，等待真实公司资料与试用反馈。尚未发布到阿里云。

## 目标

让黄油与乳制品的企业采购者快速知道主营内容、查看原料与应用方向、开始采购沟通。保留原有产品浏览和内容管理流程。本次只解决视觉表达，不增加购物车、零售价格、会员、AI 助手等功能。

上一版的奶油底色、细衬线标题、装饰英文和相似分栏被用户否定。第二版以清楚的中文排版、食品摄影和有意义的版面变化作为出发点。

## 参考与适配

先核对了现有 design-origin.md、styles.css 与设计原型。再实际读取 [awesome-design-md](https://github.com/VoltAgent/awesome-design-md) 中 [Starbucks](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/starbucks/DESIGN.md)、[Nike](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/nike/DESIGN.md)、[IBM](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/ibm/DESIGN.md) 三份 DESIGN.md：分别参考食品色块与摄影、摄影与字号层级、企业信息结构。没有复制品牌商标、专用字体、文案或完整组件。

## A：现代食品品牌（推荐）

采用明亮黄油摄影作为整幅首屏，中文无衬线标题清楚表达原料与风味；品类快捷入口、非等宽产品区域、浅色应用区和深绿咨询区形成节奏。后台采用白色工作区、安静的侧栏和清楚的草稿状态。

| Token | 值 | 用途 |
|---|---|---|
| 原料绿 | #184D32 | 标题、主要按钮、合作区域 |
| 墨色 | #202B22 | 正文与信息层级 |
| 黄油黄 | #EFD369 | 小面积品牌信号 |
| 叶浅色 | #EFF4E8 | 类别背景、管理选中态 |
| 白色 | #FFFFFF | 主画布、表单与后台 |
| 边界色 | #DCE3DB | 表格、字段与功能分隔 |

中文采用 PingFang SC / Microsoft YaHei / 系统无衬线；标题 52–84px，章节 29–38px，正文 14–16px。颜色不随便加在单个标题词上，不用英文大写标签装饰页面。桌面内容最大 1280px，手机内容留 20px 边距。按钮与表单 5px 圆角，摄影 8px，模态框 12px，层级按用途变化。

## B 与 C

B 提升应用与目录信息的密度，适合采购找资料；C 以黄油色和更强的字体、图文构图建立品牌辨识。详细规则见 b-design.md / c-design.md。三版改变构图与阅读路径，避免只换主题颜色。

## 交互与内容边界

- 品类筛选、类别详情、应用到咨询的预填、模拟咨询提交可点击。
- A 有后台产品编辑、保存草稿、模拟发布、公司资料和询盘空态。草稿保存不会改变前台已发布内容；发布只改变当前页面的设计预览，刷新会恢复。
- 产品只展示原料类别。图片为 AI 原料概念图，不等于真实 SKU、工厂或认证。不得填造规格、客户、规模、地址和联系方式。
- 模态框支持键盘 Escape 和焦点恢复；移动端导航、表格、表单需实际点验。尊重减少动态效果的系统偏好。
- 设计评审栏不属于正式官网；确认视觉后，实施时移除评审工具，使用实际 CMS 内容。
